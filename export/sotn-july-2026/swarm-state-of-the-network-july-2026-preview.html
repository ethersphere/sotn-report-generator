State of the Network: July 2026

July 2026 State of the Network Report

This report provides an overview of the Swarm network's key metrics for July 2026, including rewards, participation levels, and node distribution, and places them in context with recent monthly trends.

_Active nodes_ are full nodes identified by a unique Gnosis Chain address with the required minimum staked xBZZ that have submitted a commit transaction during the month.
All rewards are denominated in xBZZ. Since the fiat value of xBZZ fluctuates monthly, these metrics may not reflect the real-world returns for node operators.

Conclusion

In July, reward-related metrics continued to rise: total network rewards, median and average win values, and average earnings per active staking node all increased relative to June, with average earnings per node reaching their highest level since February. Participation was mixed — active staking nodes were effectively unchanged at 1,648 and total reachable full nodes rose for the first time since April, while the number of nodes winning at least once declined. Geographically, active staking remained concentrated in Finland and the broader population of reachable full nodes continued to be led by Germany, consistent with recent months.
